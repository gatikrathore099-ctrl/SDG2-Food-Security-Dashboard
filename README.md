# SDG 2 – Zero Hunger

## Global Food Security & Hunger Risk Intelligence Platform

An interactive web dashboard focused on global food security, hunger risk, crop production, food loss, and SDG 2 – Zero Hunger.

## 🌐 Live Demo

[Open the Live Website](https://gatikrathore099-ctrl.github.io/SDG2-Food-Security-Dashboard/)

## 📌 Project Overview

This project provides an interactive dashboard for exploring food-security-related information across different countries and crops.

The dashboard includes:

- Country-level food security information
- Hunger risk indicators
- Crop information
- Food production and loss information
- Crop comparison
- Interactive charts
- Country comparison
- Light and dark themes
- Responsive web interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Chart.js
- Google Fonts

## 📊 Hunger Risk Methodology

The dashboard includes an **Independent Hunger Risk Score (0–100)** developed specifically for this project.

The score uses four components:

- Food inflation
- Drought severity
- Conflict intensity
- Undernourishment

The score is a project-specific methodology and should not be interpreted as an official UN, government, or other institutional hunger-risk index.

## 🎯 SDG 2 – Zero Hunger

The project is designed around **Sustainable Development Goal 2 (SDG 2): Zero Hunger**, with a focus on understanding food security and factors that can contribute to hunger risk.

## 🚀 Running the Project Locally

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No backend server is required for the current version.
